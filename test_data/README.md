# Test Data Directory

Place your test medical images here for development and testing.

## Suggested Files

- `chest_xray_normal.png` — A normal chest X-ray
- `chest_xray_abnormal.png` — A chest X-ray with visible pathology
- `sample.dcm` — A DICOM file for testing DICOM support
- `sample_report.pdf` — A sample radiology report PDF

## Where to Get Test Images

1. **NIH Chest X-ray Dataset**: https://nihcc.app.box.com/v/ChestXray-NIHCC
2. **Radiopaedia DICOM samples**: https://radiopaedia.org/
3. **OHIF sample DICOM data**: https://docs.ohif.org/
4. **Sample radiology PDFs**: Search for "sample radiology report template PDF"
